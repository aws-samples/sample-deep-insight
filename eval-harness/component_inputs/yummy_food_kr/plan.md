# Plan

## thought
사용자는 광고 성과 데이터(yummy-food-market.csv)와 컬럼 정의(column_definitions.json)를 기반으로 매체별·카테고리별·상품별 CTR, 전환율, ROAS를 분석하고, 광고비의 효율/낭비 지점을 식별한 뒤 우선순위와 기대 효과가 포함된 실행 전략 3가지를 DOCX로 받기를 원합니다.

1. CTR, 전환율, ROAS 등 다수의 수치 계산 및 세그먼트 집계가 필요 → Coder
2. 모든 지표 계산이 수치 기반이므로 검증 필수 → Validator
3. DOCX 보고서 생성 → Reporter (문서 생성은 Reporter 전담)
4. 인용 마커가 포함된 DOCX가 산출되므로 → Auditor 1회

한국어로 응답합니다.

## title
Yummy Food Market 광고 성과(CTR·전환율·ROAS) 효율 분석 및 광고비 최적화 전략 수립

## steps

### 1. Coder: 광고 성과 데이터 다차원 효율 분석
- [ ] `column_definitions.json`을 먼저 로드하여 각 컬럼의 의미·단위·지표 정의를 파악하고, 분석에 사용할 컬럼 매핑 정리
- [ ] `yummy-food-market.csv` 로드 및 데이터 프로파일링 (행/열 수, 결측치, 이상치, 데이터 타입, 기간 범위, 매체/카테고리/상품 카디널리티)
- [ ] 핵심 지표 산출 로직 정의 및 계산: CTR(클릭/노출), CVR(전환/클릭), ROAS(매출/광고비), CPC, CPA, CPM, 전환당 매출(AOV) — 분모 0 처리 규칙 명시
- [ ] 전체 벤치마크(총 광고비, 총 매출, 통합 CTR/CVR/ROAS) 산출하여 비교 기준선 확보
- [ ] 매체(media/channel)별 성과 집계: 광고비 점유율, 매출 기여도, CTR·CVR·ROAS·CPA 비교 및 벤치마크 대비 상대 성과
- [ ] 카테고리별 성과 집계: 광고비 대비 매출 기여 효율, ROAS 순위, 카테고리별 전환 퍼널(노출→클릭→전환) 이탈 구간 식별
- [ ] 상품별 성과 집계: ROAS 상·하위 상품 Top/Bottom 랭킹, 광고비 투입 규모 대비 효율 산포 분석
- [ ] 매체 × 카테고리 교차 분석으로 "고효율 조합"과 "저효율 조합" 매트릭스 도출
- [ ] 시간 흐름 컬럼이 존재할 경우, 기간별 CTR·CVR·ROAS 추이 및 성과 변동성 분석
- [ ] 광고비 낭비 규모 정량화: ROAS가 손익분기(ROAS=1) 또는 전체 평균 미달인 세그먼트의 광고비 합계와 비중 계산, 재배분 가능 예산 규모 추정
- [ ] 효율 구간 정량화: 상위 ROAS 세그먼트의 한계 수익성 추정 및 예산 증액 시 기대 매출 증분 시나리오 계산 (보수적 가정 명시)
- [ ] 지표 간 상관관계 분석 (예: CTR↔CVR, 광고비 규모↔ROAS)으로 "클릭은 많지만 전환이 안 되는" 유형 vs "노출 부족" 유형 진단
- [ ] 핵심 시각화 생성: ① 매체별 광고비 vs 매출/ROAS 비교 차트 ② 카테고리별 CTR·CVR·ROAS 비교 차트 ③ 상품별 ROAS Top/Bottom 랭킹 차트 ④ 광고비 vs ROAS 산점도(버블 크기=매출) ⑤ 매체×카테고리 ROAS 히트맵 ⑥ (기간 데이터 존재 시) 지표 추이 라인 차트
- [ ] 분석 결과를 바탕으로 광고비 효율 개선 전략 3가지 도출 — 각 전략별 근거 수치, 실행 방법, 우선순위(High/Medium) 판단 기준, 기대 효과(ROAS 개선폭·절감 광고비·증분 매출 추정치) 수치화
- [ ] 모든 계산에 대한 calculation metadata 생성 (지표명, 산식, 입력값, 결과값, 데이터 출처 범위)

### 2. Validator: 지표 계산 검증 및 인용 메타데이터 생성
- [ ] Coder가 산출한 CTR·CVR·ROAS·CPC·CPA 등 전 지표의 산식 적정성 검토 (가중평균 vs 단순평균 사용 적절성 포함)
- [ ] 매체별·카테고리별·상품별 집계값 재계산 및 원본 데이터와 교차 검증
- [ ] 총 광고비·총 매출·전체 ROAS 합계 정합성 확인 (세그먼트 합 = 전체 일치 여부)
- [ ] 광고비 낭비 규모 및 예산 재배분 시나리오의 기대 효과 추정치 재계산 및 가정의 합리성 검증
- [ ] 차트에 사용된 데이터값 정확성 검증
- [ ] 통계적 해석(상관관계, 순위, 이상치 판정)의 타당성 확인
- [ ] 검증된 핵심 수치에 대한 citation metadata 생성 (각 수치별 인용 번호 매핑)

### 3. Reporter: 광고비 효율 분석 및 최적화 전략 보고서 작성 (DOCX)
- [ ] 검증된 분석 결과를 종합하여 구조화된 보고서 작성: 요약(Executive Summary) → 데이터 개요 → 전체 광고 성과 현황 → 매체별 분석 → 카테고리별 분석 → 상품별 분석 → 효율/낭비 구간 진단 → 실행 전략 3가지 → 결론
- [ ] 광고비가 효율적으로 쓰이는 구간과 낭비되는 구간을 수치와 함께 명확히 대비하여 제시
- [ ] 실행 전략 3가지를 우선순위(1순위/2순위/3순위), 실행 방법, 소요 리소스, 기대 효과(정량 추정치), 측정 KPI를 포함한 표 형식으로 정리
- [ ] 모든 시각화 자료를 적절한 섹션에 배치하고 각 차트에 대한 해석 문장 추가
- [ ] 검증된 수치에 인용 번호 [1], [2], ... 삽입 및 참고문헌(References) 섹션 추가
- [ ] 표준 파일명으로 DOCX 보고서 생성 (report_draft.docx, final_report.docx, final_report_with_citations.docx)

### 4. Auditor: 보고서 인용 정합성 감사
- [ ] `final_report_with_citations.docx`를 대상으로 DeepTRACE Type A/B/C/D 인용 결함 독립 감사 수행
- [ ] 본문 수치와 인용 메타데이터 간 일치 여부, 미인용 수치, 잘못된 인용 매핑, 근거 없는 주장 검출
- [ ] `audit_findings.json` 및 `audit_report.txt` 산출
- [ ] 최종 판정(PASS / RETRY / NEEDS_REVIEW) 발행
